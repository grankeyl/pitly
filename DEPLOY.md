# Бесплатное размещение Pitly

Схема: сервер и mini app в одном контейнере на Render, база данных в Neon.
Оба сервиса бесплатные, карта не нужна. Адрес вида `https://pitly.onrender.com` с HTTPS выдается бесплатно.

## Ограничения бесплатного тарифа

- Render усыпляет сервис после 15 минут без запросов. Первое открытие после сна занимает 30-60 секунд.
  Бот работает через вебхук, поэтому Telegram сам будит сервис, когда приходит сообщение.
- Neon дает 0,5 ГБ хранилища и тоже засыпает без запросов; просыпается за секунду.
- Тестовая оплата остается: настоящий платежный провайдер не подключен.

## Шаг 1. База данных в Neon

1. Зарегистрируйтесь на https://neon.tech и создайте проект в регионе Europe (Frankfurt).
2. Скопируйте строку подключения `postgresql://...` с параметром `?sslmode=require`.

## Шаг 2. Код на GitHub

Render берет код из репозитория. Файлы `backend/.env` и ключи в репозиторий не попадают, они в `.gitignore`.

```bash
git init && git add -A && git commit -m "Pitly" && gh repo create pitly --private --source=. --push
```

## Шаг 3. Сервис на Render

1. Зарегистрируйтесь на https://render.com через GitHub.
2. New → Blueprint → выберите репозиторий. Render прочитает `render.yaml` и попросит два значения:
   - `DATABASE_URL`: строка из Neon;
   - `BOT_TOKEN`: токен из BotFather.
3. Нажмите Apply и дождитесь статуса Live. Адрес сервиса появится вверху страницы.

## Шаг 4. Telegram

1. В BotFather: `/mybots` → PitlyBot → Bot Settings → Configure Mini App → включите и вставьте адрес сервиса.
2. Кнопку меню и вебхук сервер настраивает сам при запуске.

## Обновление

Каждый `git push` в основную ветку пересобирает и перезапускает сервис.

## Если нужно без сна

Платный тариф Render Starter (около 7 долларов в месяц) убирает засыпание. Другой вариант: любой VPS и `deploy/docker-compose.yml` со своим доменом.
